# Denim WD Regular — Terms & Conditions

Place your licensed `DenimWD-Regular.otf` file in this folder:

`public/fonts/denim/DenimWD-Regular.otf`

Only the scrollable T&C paragraphs and lists use this face. The numbered
headings, title and action buttons retain National 2 Compressed Bold Italic.

The font supplied in `denim-font-family.zip` is labelled TRIAL / Personal Use
Only: use it solely for local visual evaluation, not for public deployment.
Font binaries are deliberately not redistributed with this project.
